# Arkhe

El sitio actualizado está en [web/](web/). Para abrirlo en tu computadora, descargá la rama y abrí web/index.html en el navegador.

## Enviar ficha

El [servicio de fichas](fichas-arkhe/README.md) añade a Personajes el formulario, la revisión privada y la publicación de fichas aprobadas. GitHub aloja el código. Para recibir envíos reales, ejecutá el servicio en un alojamiento con Node.js, HTTPS y almacenamiento privado persistente.
